# Projeto captura de dados aberto Curitiba - SIAC

## Objetivo

Obter os dados abertos da prefeitura de Curitiba, inicialmente do Sistema Integrado de Atendimento ao Cidadão - SIAC 156.
Aplicar técnicas de engenharia de dados executando o caminho desde a obtenção até a disponibilização em dashboard.

## Fonte de dados

-  https://dadosabertos.curitiba.pr.gov.br/conjuntodado/detalhe/?chave=0d5a7b06-3940-4be9-876e-bc8f23e96530

## Detalhamento e tecnologias

- Desenvolver em python
- Aplicar camada para obtenção dos dados da fonte, e validar se o serviço foi executado corretamente, caso não seja: gerar log
- Utilizar fastAPI
- Armazenar os dados
- Aplicar dbt
- Validar os dados
- Apresentar relatorio e dashboard
- Dashboard em apache echarts
- Escrever testes
